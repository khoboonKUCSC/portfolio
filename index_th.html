Computer Vision & Deep Learning

ระบบตรวจจับหลุม ท่อระบายน้ำ และรอยแตกบนพื้นผิวถนนด้วยกล้องหน้ารถยนต์

การประยุกต์ใช้โมเดล Computer Vision ในการตรวจจับและจำแนกความเสียหายบนพื้นผิวถนน ได้แก่ หลุม (Pothole), ฝาท่อระบายน้ำ (Manhole) และรอยแตก (Crack) แบบเรียลไทม์จากภาพและวิดีโอกล้องหน้ารถยนต์ เพื่อสนับสนุนการซ่อมบำรุงทางหลวงและความปลอดภัยในการขับขี่

สถาปัตยกรรมและขั้นตอนการทำงานของระบบ (Pipeline)
STEP 01
รับสัญญาณภาพ (Input)
ดึงเฟรมวิดีโอจากกล้องหน้ารถยนต์ในสภาวะแสงและสภาพแวดล้อมที่หลากหลาย
STEP 02
การเตรียมข้อมูลภาพ (Preprocessing)
ลดสัญญาณรบกวน ปรับสมดุลคอนทราสต์ และกำหนดขอบเขตพื้นที่ถนน (ROI)
STEP 03
ตรวจจับและจำแนก (Detection & Classification)
ระบุพิกัดและจำแนกประเภทหลุม ฝาท่อระบายน้ำ และรอยแตกร้าว
STEP 04
ประเมินระดับและแจ้งเตือน (Alerting)
คำนวณระดับความเสี่ยงและส่งต่อพิกัดเตือนผู้ขับขี่หรือแจ้งศูนย์ซ่อมบำรุง
Python Computer Vision Image Classification Machine Learning Object Detection
